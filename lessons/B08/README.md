# HP12 – B08: Quản lý dự án với GitHub

**Sản phẩm:** GitHub Release Starter

## Giới thiệu và bối cảnh
Bài học là một phần trong hành trình kết thúc bốn học phần Web Design & Development. **Yêu cầu quan sát:** Tổ chức mã nguồn vào repository GitHub và tạo ít nhất một commit có mô tả rõ; đọc được lịch sử thay đổi.

**Kiến thức kế thừa:** HP10: cấu trúc tệp website; HP11: dự án JavaScript; HP12 B01–B07: các chức năng đã kiểm thử.

## Cấu trúc source/asset
- `index.html`: giao diện bài học có thể chạy độc lập.
- `src/style.css`: bố cục, màu sắc và các trạng thái.
- `src/app.js`: mã JavaScript hoàn chỉnh.
- `assets/illustration.svg`: asset SVG tự tạo, không phụ thuộc Internet.
- `KNOWLEDGE.md`, `BUILD_STEPS.md`, `RUN_AND_INTERACT.md`, `TEST_CASES.md`, `SOURCE_MAP.md`: tài liệu học tập và nghiệm thu.

## Tiêu chí hoàn thành
1. Repository học sinh/nhóm chứa đầy đủ mã nguồn HTML, CSS, JS, asset.
2. Lịch sử có ít nhất một commit có mô tả rõ.
3. Không có token, mật khẩu hoặc dữ liệu riêng tư trong file công khai.
4. Bảng kiểm trên trang hoạt động khi đánh dấu/bỏ đánh dấu.

**Không thuộc phạm vi bắt buộc:** backend, database, framework hay công nghệ mới vượt mục tiêu.

**Mở rộng:** Thực hiện thêm một commit cho chỉnh sửa bố cục và giải thích sự khác nhau giữa hai phiên bản.
