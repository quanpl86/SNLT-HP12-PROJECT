# Sơ đồ mã nguồn và tài nguyên — B11

| File | Nội dung | Vai trò người học |
|---|---|---|
| `index.html` | Cấu trúc trang và nhãn điều khiển | Xác định vùng cần hoàn thiện |
| `src/style.css` | Kiểu trình bày responsive và trạng thái | Liên hệ Figma/HP10, chỉnh giao diện khi cần |
| `src/app.js` | Mã hoạt động đầy đủ của bài học | Đọc, thay đổi, chạy thử, gỡ lỗi |
| `assets/illustration.svg` | Hình tự tạo | Tái sử dụng hoặc thay bằng asset phù hợp |
| Các tệp Markdown | Quy trình, kiến thức, nghiệm thu | Hỗ trợ xây dựng và trình bày minh chứng |

**Liên hệ dự án cuối khóa:** Thư mục này là bài thực hành độc lập; sản phẩm tích hợp là site tại root repository. Không cần ghép nguyên trang mini vào website cuối khóa nếu chỉ muốn chuyển một hàm hoặc hành vi.
