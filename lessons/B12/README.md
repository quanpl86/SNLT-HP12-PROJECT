# HP12 – B12: Dự án cuối khóa — Chia sẻ dự án

**Sản phẩm:** Four-HP Web Portfolio

## Giới thiệu và bối cảnh
Bài học là một phần trong hành trình kết thúc bốn học phần Web Design & Development. **Yêu cầu quan sát:** Trình diễn Web Blog, giải thích quá trình tích hợp Figma → HTML/CSS → JavaScript → phát hành, và phản tư về cải tiến.

**Kiến thức kế thừa:** Toàn bộ hành trình HP09–HP12 và kết quả các dự án B01–B11.

## Cấu trúc source/asset
- `index.html`: giao diện bài học có thể chạy độc lập.
- `src/style.css`: bố cục, màu sắc và các trạng thái.
- `src/app.js`: mã JavaScript hoàn chỉnh.
- `assets/illustration.svg`: asset SVG tự tạo, không phụ thuộc Internet.
- `KNOWLEDGE.md`, `BUILD_STEPS.md`, `RUN_AND_INTERACT.md`, `TEST_CASES.md`, `SOURCE_MAP.md`: tài liệu học tập và nghiệm thu.

## Tiêu chí hoàn thành
1. Có liên kết hoặc bản chạy của sản phẩm cuối khóa.
2. Có minh chứng tối thiểu từ ba chặng Figma, HTML/CSS và JavaScript.
3. Giải thích được ít nhất một cơ chế JavaScript đã triển khai.
4. Có nhật ký lỗi hoặc kiểm thử và nêu được một giới hạn kỹ thuật.

**Không thuộc phạm vi bắt buộc:** backend, database, framework hay công nghệ mới vượt mục tiêu.

**Mở rộng:** Chuẩn bị video thuyết trình ngắn không để lộ thông tin cá nhân.
