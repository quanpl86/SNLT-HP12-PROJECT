# B10 — Triển khai dự án cuối khóa thật

**Xuất bản thư mục gốc repo (root site), không phải một riêng mini project.**

1. Truy cập repository trên GitHub mà học sinh có quyền quản lý.
2. Kiểm tra trang chủ tên `index.html` nằm ở root.
3. Chọn **Settings → Pages → Build and deployment → Deploy from a branch** (nếu GitHub hiển thị tùy chọn này).
4. Chọn **main**, **/(root)** và Save.
5. Kiểm tra thông báo trạng thái triển khai; lấy URL đúng từ GitHub Pages settings.
6. Mở URL thật và kiểm tra ảnh, CSS, JS, điều hướng, tìm kiếm/lọc, Editor.
7. Nếu GitHub báo lỗi quyền hoặc triển khai: ghi lại lỗi, nhờ giáo viên hướng dẫn, không đánh dấu hoàn thành giả.
8. Ghi link phát hành, mã commit và ảnh kết quả vào báo cáo.

Mã trong thư mục gốc repository này là một **mẫu website tĩnh có thể chọn làm bản sản phẩm hoàn chỉnh**. GitHub Pages không tạo database, không đăng bài công khai từ LocalStorage.
