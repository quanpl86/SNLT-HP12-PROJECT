# HP12 – B10: Dự án cuối khóa — Hoàn thiện và xuất bản Web Blog

**Bối cảnh “Sắc Việt”:** Hoàn thiện và xuất bản website Sắc Việt qua GitHub Pages ở bài 10; không tạo thêm chức năng ngoài yêu cầu.

**Lưu ý:** Nội dung chủ đề không làm thay đổi mục tiêu JavaScript, GitHub và kiểm thử của bài. Học sinh sử dụng dữ liệu mẫu, không đăng thông tin cá nhân.

**Sản phẩm:** First Published Blog v1.0

## Giới thiệu và bối cảnh
Bài học là một phần trong hành trình kết thúc bốn học phần Web Design & Development. **Yêu cầu quan sát:** Tích hợp website đã chuẩn bị và thực hiện phát hành GitHub Pages, kiểm tra URL được GitHub cung cấp.

**Kiến thức kế thừa:** HP09: Figma; HP10: HTML/CSS; HP11: JS; HP12 B08 repository, B09 pre-release QA.

## Cấu trúc source/asset
- `index.html`: giao diện bài học có thể chạy độc lập.
- `src/style.css`: bố cục, màu sắc và các trạng thái.
- `src/app.js`: mã JavaScript hoàn chỉnh.
- `assets/illustration.svg`: asset SVG tự tạo, không phụ thuộc Internet.
- `KNOWLEDGE.md`, `BUILD_STEPS.md`, `RUN_AND_INTERACT.md`, `TEST_CASES.md`, `SOURCE_MAP.md`: tài liệu học tập và nghiệm thu.

## Tiêu chí hoàn thành
1. Website tổng kết chạy ở localhost không có lỗi JS cản trở.
2. Trang chủ, CSS và ảnh SVG hiển thị từ URL được GitHub cung cấp sau khi triển khai.
3. Tìm kiếm/lọc và liên kết hoạt động trên URL thực tế.
4. Hồ sơ phát hành không tuyên bố hoàn tất khi Pages chưa được bật hoặc chưa kiểm thử.

**Không thuộc phạm vi bắt buộc:** backend, database, framework hay công nghệ mới vượt mục tiêu.

**Mở rộng:** Thêm liên kết giới thiệu dự án HP09–HP11 ở trang About rồi tạo commit.
