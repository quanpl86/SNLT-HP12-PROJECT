# Hướng dẫn chạy và tương tác — B09

1. Clone/download repository về máy (hoặc mở thư mục trong VS Code).
2. Mở terminal tại **thư mục gốc repository** và chạy `python -m http.server 8000` (hoặc VS Code Live Server).
3. Truy cập `http://localhost:8000/lessons/B09/`.
4. Quan sát giao diện, đọc tên sản phẩm và mô tả mục tiêu.
5. Thực hiện các tình huống sau:
   1. Tìm Hội An hiển thị đúng bài Hội An.
   2. Nhập khôngtontai hiển thị 0 kết quả.
   3. Nháp được lưu và khôi phục sau tải lại trang.
   4. Có issue log ít nhất một tình huống trước/sau sửa.
6. Nếu chức năng lỗi, mở DevTools Console; kiểm tra đường dẫn, selector và các giá trị dữ liệu.
7. Ghi lại ít nhất một thử nghiệm/thay đổi trong mã hoặc quy trình triển khai có bằng chứng.

**Lưu ý GitHub Pages:** B08 chuẩn bị repo, B10 thực sự xuất bản, B11 kiểm thử lại. Trang checklist mô phỏng **không** tự xuất bản website.
